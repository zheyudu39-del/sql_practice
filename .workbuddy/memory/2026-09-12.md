## 追加答疑（16:26）：用户陷入"粘贴报错→产生新报错→再粘贴"的死循环
- 症状：控制台出现 `->` 与 `'>` 两种续行提示符。`'>` = **单引号未闭合**（用户把报错文本里的 `'...'` 一起粘进去了），`->` = 缺分号。
- 两者都能用 `\c` 回车清空缓冲恢复；不行就 Ctrl+C；再不行 `exit` 重连。
- 对初学者的关键纪律：**只复制纯 SQL，不要连提示符 `MariaDB [shop]>` / `-> ` / `ERROR ...` 一起复制**；长 DDL 一律 `source` 跑文件，不手敲不粘贴。
- 教学提示有效的做法：用「提示符状态对照图」（正常 `MariaDB [shop]>` / `->` / `'>`）解释，比纯文字有效。

## 追加答疑（16:31）
- 解释 `) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;`：表选项（写在列定义 `)` 之后），ENGINE = 存储引擎（决定事务/行级锁/外键支持），DEFAULT CHARSET = 表级默认字符集（所有未单独指定的字符列都继承它）。
